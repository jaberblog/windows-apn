# Vira VPN (Flutter Windows + Xray-core)

کلاینت بومی VPN برای ویندوز با فلاتر، هسته رسمی **Xray-core** و دریافت خودکار سرورها از `https://virasub.ir/npv/`.

## امکانات
- دکمه اتصال و قطع اتصال با انیمیشن پالس راداری و چرخشی
- اتصال واقعی روی ویندوز از طریق اجرای `xray.exe` و تنظیم خودکار System Proxy ویندوز
- نمایش لحظه‌ای سرعت دانلود و آپلود (`B/s`, `KB/s`, `MB/s`) و حجم کل مصرفی از طریق Stats API هسته Xray
- دریافت لیست کانفیگ‌ها فقط از API `https://virasub.ir/npv/` (پشتیبانی از JSON، Base64 و لینک‌های `vless://`)
- پشتیبانی کامل از پروتکل‌های انتقال (`TCP`, `WS`, `gRPC`, `HTTPUpgrade`, `XHTTP`) و امنیت (`TLS`, `Reality`)
- نمایش آیکون، عنوان و آدرس سرور به صورت لیست همراه با تست پینگ تک‌تک و همگانی

## نحوه دریافت خروجی EXE از طریق GitHub
1. محتویات این فایل ZIP را در یک مخزن (Repository) جدید در GitHub آپلود کنید.
2. وارد تب **Actions** در مخزن گیتهاب شوید؛ ورک‌فلو **Build Windows EXE** به صورت خودکار برنامه فلاتر را بیلد کرده، آخرین نسخه `xray.exe` را دانلود و در کنار `vira_vpn.exe` قرار می‌دهد.
3. پس از اتمام بیلد، از بخش **Artifacts** فایل `ViraVPN-Windows-x64.zip` را دانلود کرده، اکسترکت کنید و `vira_vpn.exe` را اجرا نمایید.
